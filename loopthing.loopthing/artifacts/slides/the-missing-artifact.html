The Missing Artifact

We have GitHub for code. We do not have a portable artifact for the thinking loops behind AI work.

AI work happens in loops.

You prompt, critique, branch, kill ideas, revise, and produce artifacts.

Raw chat is chaos. Final output is too compressed.

The useful process disappears in both directions.

.loopthing is a package.

Sanitized prompt, track changes, killed directions, reasons, slides, docs, code, prototypes, and the graph of thought.

The output is no longer the only artifact.

The thinking ships too.
