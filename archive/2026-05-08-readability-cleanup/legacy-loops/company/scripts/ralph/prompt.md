# LoopThing Ralph Agent Instructions

You are a fresh agent loop working on one area of LoopThing.

## Your Task

1. Read the selected area's `prd.json`.
2. Read the selected area's `progress.txt`.
3. Read `loops/company/AGENTS.md`.
4. Pick the highest-priority story where `passes: false`.
5. Work on that single story only.
6. Write or update the smallest durable artifact needed for the story.
7. Run any relevant checks.
8. Append learnings to the area's `progress.txt`.
9. Do not mark the story passed unless the user or runner explicitly asks.

## Output Standard

Every story should leave behind something future loops can reuse: a plan, scorecard, artifact, script, design spec, pricing table, launch post, test protocol, or implementation.

## LoopThing Product Context

LoopThing turns messy AI conversations into compressed reasoning artifacts for handoff. The wedge is not memory, not "summarize chat," and not a decorative viewer. The product has to prove compression quality first.

## Brand Context

The brand needs to win trust. It should feel like a high-signal reasoning object, not a hypey AI dashboard. Use the Refero-style approach: extract taste into explicit colors, typography, layout rules, components, and "do not" rules that future agents can follow.
