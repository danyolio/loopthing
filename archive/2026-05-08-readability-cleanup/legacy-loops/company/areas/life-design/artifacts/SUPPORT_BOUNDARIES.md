# Support Boundaries

## Principle

LoopThing should not become consulting with a file extension.

Support should help users run the product and understand the artifact. It should not become custom reasoning labor.

## Allowed Support

- import/export help
- CLI installation help
- bug reports
- artifact structure questions
- scoring protocol questions
- redaction/privacy guidance

## Not Allowed By Default

- writing the user's strategy
- editing every artifact by hand
- custom enterprise deployment
- bespoke template design before repeatable demand
- live onboarding calls for every small account
- "can you just clean this chat for me?" as the product

## Support Modes

Free/Pro:

- docs
- examples
- async issue form

Team:

- async support
- office hours once per week
- shared templates

Founding Teams:

- capped onboarding
- two artifact reviews per month
- no unlimited consulting

## Escalation Triggers

Hire contractor support when support exceeds 5 hours/week for 3 consecutive weeks.

Consider first part-time operator when support or onboarding blocks product work twice in one month.

Kill or reprice any plan where support minutes per $100 MRR exceed 30 minutes.
