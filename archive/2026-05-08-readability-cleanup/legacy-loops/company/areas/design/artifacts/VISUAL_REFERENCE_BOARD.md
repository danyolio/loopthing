# Visual Reference Board

## Source Method

Refero's useful frame is "Design taste, extracted": search curated references and turn them into concrete colors, type, spacing, components, and a `DESIGN.md` an agent can use.

LoopThing should use that method, but the references should be judged against the product's trust job: make a compressed reasoning artifact feel worth sending.

## Reference Directions To Pull

### Editorial Evidence Packet

Use for: typography, page rhythm, credibility.

Rules to extract:

- high contrast type
- clear section hierarchy
- generous margins
- exact captions
- no decorative AI visuals

### Technical File Object

Use for: the `.loopthing` object.

Rules to extract:

- filename and MIME marker visible
- checksums/source metadata as trust signals
- compact inspector labels
- file feels portable, not decorative

### Whiteboard Lineage

Use for: journey maps and discarded branches.

Rules to extract:

- boxes and arrows
- handwritten looseness only in the diagram layer
- killed branches dimmed but legible
- kill reasons inline

### Field Notebook

Use for: creator trust and process honesty.

Rules to extract:

- paper/ink palette
- annotations
- marginalia
- exact quotes

### Developer Tool

Use for: CLI and local-first posture.

Rules to extract:

- plain commands
- visible outputs
- predictable file tree
- no setup theater
