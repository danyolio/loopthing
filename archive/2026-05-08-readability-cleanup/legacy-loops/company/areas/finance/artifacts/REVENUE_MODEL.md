# Revenue Model Notes

The editable model is `revenue-model.csv`.

## Best Early Path

Use a capped founding-team program to reach $10k MRR:

- 10 teams
- $1,000/month
- strict scope: compression challenge, CLI feedback, artifact review
- no custom deployments

## $100k MRR Path

Blend Pro and Team:

- 1,000 Pro users x $39 = $39k
- 250 Team workspaces x $249 = $62.25k
- total: $101.25k MRR

## $1M MRR Path

Requires org/team motion:

- 2,000 workspaces x $500
- or 500 orgs x $2,000

This is not solo in any honest operating model.

## Sensitivities To Track Later

- activation rate from imported chat to sendable artifact
- percentage of artifacts sent to a recipient
- recipient comprehension score
- support minutes per workspace
- churn from "interesting" to "habit"
