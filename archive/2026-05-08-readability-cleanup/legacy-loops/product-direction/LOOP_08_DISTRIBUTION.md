# Loop 08: Distribution Wedge

## Question

How does this reach the first real users?

## Branches

### Launch The File Format

**Thesis:** Publish the `.loopthing` spec and invite people to adopt it.

**Critique:** Nobody adopts a file format for a problem they cannot yet feel.

**Verdict:** Killed before proof.

### Publish A Thesis Post

**Thesis:** Explain "semantic decision layer" and attract category believers.

**Critique:** Good for narrative, weak for validation. Likes are not handoff behavior.

**Verdict:** Survivor after test results.

### Open-Source Compression Harness

**Thesis:** Ship a tiny local tool and ask AI-native builders to run it on real chats.

**Critique:** Small audience, but that is acceptable for the first wedge.

**Regenerated:** Pair it with a public "compression challenge": bring a messy chat, compare generic summary vs LoopThing artifact, score handoff.

**Verdict:** Pinned.

### Private Handoff Concierge

**Thesis:** Manually run the process for 5-10 trusted users and observe whether they send the artifact.

**Critique:** Not scalable, but extremely high-signal.

**Verdict:** Survivor. Use alongside the harness.

## Pinned Distribution

Start with a private compression challenge for AI-native builders, then open-source the harness with anonymized before/after examples.

## Why This Wins

It creates evidence before audience. It tests whether people actually have chats with gold in them and whether a recipient can inherit the reasoning.
