# Ralph Loop Frame: LoopThing Product Direction

## Chosen Question

What is the strongest product direction hiding in LoopThing right now?

## Why This Question

The project has moved through several plausible identities: thought-history file format, rich PDF for AI work, viewer, repo explainer, memory layer, and semantic decision layer. The current risk is building infrastructure before proving the core value. The highest-leverage question is therefore not "what should the format contain?" but "what wedge makes LoopThing necessary?"

## Constraints

- Compression quality must be testable before infrastructure.
- The wedge must avoid direct competition with lab memory features.
- The product must produce value for the creator first.
- Handoff must be legible to someone who was not in the original conversation.
- The direction must be concrete enough to build this weekend.
- Viewer, container, and media artifacts are supporting surfaces, not the product center.

## Method

Ralph Loop method used:

1. Inventory the current project.
2. Generate divergent product branches.
3. Critique each branch.
4. Regenerate the strongest branches.
5. Kill weak branches with reasons.
6. Pin the strongest survivor.
7. Seal the result into a project artifact.
