# Initial Prompt

The earliest version asked for a demo that could show how an idea arrived, not just what the final output looked like.

That broad request produced useful branches, but the current product claim is narrower:

```text
Compress messy AI work into a handoff artifact.
Make the next chat, agent, collaborator, or future self start from the real state of the work.
```

Archived origin-trace demos are useful lineage, not current public positioning.
