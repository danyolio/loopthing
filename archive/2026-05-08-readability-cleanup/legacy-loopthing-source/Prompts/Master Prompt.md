# Master Prompt

Build LoopThing as a compression-first handoff product.

A `.loopthing` is a compressed reasoning artifact for AI work. It turns messy chats, project notes, prompts, and generated files into a handoff someone else can use without reading the transcript.

The public claim:

```text
Raw chats keep everything.
Summaries flatten everything.
LoopThing keeps the moves that matter.
```

## Required Story

AI work now happens in long sessions. A final output hides the decisions that made it good; a raw transcript preserves too much. LoopThing extracts the load-bearing structure:

- intent
- decisions
- critical turns
- discarded branches
- risks
- asks
- next actions

The entrypoint is `agent-handoff.md`: paste-ready context for a fresh AI session, collaborator, or future self.

## Product Requirement

The viewer can be beautiful, but beauty is not the proof.

The proof is whether a fresh session can continue from the handoff.
