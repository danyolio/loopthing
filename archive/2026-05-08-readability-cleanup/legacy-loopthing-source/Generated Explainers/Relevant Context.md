# Relevant Context

## Git

Git tracks code diffs. LoopThing tracks the exploration that produced the work.

## Handoff Docs

A good handoff is not a transcript and not a slide deck. It is the smallest context packet that lets the next person or agent continue from the real state of the work.

## Tree Of Thoughts

Tree-of-thought style systems explore branches, but the exploration is usually algorithmic and ephemeral. LoopThing focuses on the shareable handoff after real work has happened.

## Agent Audit Trails

Audit logs can record what happened for compliance. LoopThing is different: it is designed for inheriting the reasoning, not just proving a system behaved.

## Design Space Exploration

Design tools can map alternatives, but they are usually domain-specific. LoopThing treats reasoning handoff itself as the product surface.
