# Agent Handoff

Every LoopThing run now writes `agent-handoff.md`.

This is the sharpest product improvement from the latest product loop. A readable artifact is useful, but a paste-ready continuation brief is testable.

## Test

Paste `agent-handoff.md` into a fresh AI session.

If the new session understands the product spine, killed branches, risks, and next action without reading the transcript, LoopThing worked.

## Why It Matters

Raw chats keep too much. Summaries lose the moves. Agent handoff keeps the load-bearing context small enough to move.
