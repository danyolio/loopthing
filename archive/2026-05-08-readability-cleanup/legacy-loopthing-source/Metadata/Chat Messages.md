## Primitives

- Reasoning compression: intent, critical messages, framing diffs, discarded branches, risks, outcome, and next action.
- Agent handoff: paste-ready context for a fresh AI session, collaborator, or future self.
- Source metadata: message counts, topics, source shape, and file checksums.
