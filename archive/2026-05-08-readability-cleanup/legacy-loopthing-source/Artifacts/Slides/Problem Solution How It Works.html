Your next session should not start cold.

LoopThing compresses messy AI work into a handoff artifact for the next chat, agent, collaborator, or future self.

Problem

Raw chats keep everything. Summaries flatten everything. The useful reasoning lives between them: decisions, direction, killed paths, risks, and next action.

Solution

.loopthing is a portable reasoning container. Its key output is agent-handoff.md: paste-ready context for a fresh AI session.

Current demo facts

100 source messages across 86 files became a reasoning artifact, source metadata, structural score, and one agent handoff.

How It Works

READ the source. COMPRESS the reasoning. Preserve discarded branches. Generate a handoff. SEAL the run into a portable .loopthing.

The honest test

Paste the handoff into a new session. If it continues from the real state of the work, LoopThing worked. If it does not, the compressor failed.
