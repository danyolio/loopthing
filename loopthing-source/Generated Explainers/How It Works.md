# How It Works

1. Start with the session.

The raw material is the user's prompts, follow-ups, revisions, and artifacts created during the AI work.

2. Extract the spine.

LoopThing treats user prompts as the primary record. AI responses can be useful, but the human direction is the canonical process.

3. Generate explainers.

The container creates net new artifacts that did not exist in the chat: problem statements, solution summaries, journey maps, related context, and share briefs.

4. Preserve judgment.

Discarded ideas are kept with reasons. This makes the creator look more deliberate, not less.

5. Package the work.

The `.loopthing` file carries prompts, drafts, screenshots, docs, slides, prototypes, code, and generated explainers as one shareable object.
