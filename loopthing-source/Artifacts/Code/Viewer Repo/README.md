# Viewer Repo

This folder is the code artifact carried inside the `.loopthing`.

The full repo-level viewer is `index.html` at the root of the public GitHub repo. This contained version is a small static viewer example that proves a `.loopthing` can carry code alongside prompts, slides, and thought process.

## Included

- `index.html`: a tiny package-browser prototype

## Why It Is Here

Code alone does not explain how the idea arrived. Inside a `.loopthing`, the code artifact travels with prompts, follow-ups, discarded ideas, generated explainers, screenshots, slides, and the journey map that shaped it.
