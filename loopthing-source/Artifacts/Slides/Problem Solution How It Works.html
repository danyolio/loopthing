The Missing Artifact

We have GitHub for code. We do not have a file for the thinking loop behind AI work.

Problem

Raw chats are too noisy to share. Final outputs hide the decisions that made the work good.

Solution

.loopthing is a portable container: prompts, decisions, killed branches, journey map, and artifacts in one file.

How It Works

The master prompt becomes the entrypoint. Raw user prompts become the spine. Killed directions show judgment. Artifacts prove the loop shipped.

Why Share It

A LoopThing makes exploratory work skimmable, forkable, and impressive without dumping the messy chat.
