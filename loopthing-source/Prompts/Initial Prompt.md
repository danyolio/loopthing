# Initial Prompt

The true origin was an OpenAI Codex hackathon demo, before the OpenClaw version existed.

```text
Write a prompt to help me build a demo that can show the most wow parts of my script.
This must be done in less than 30 minutes.
Actually loopthing the repo below.
Show a suggested initial prompt.
Potential inspirations.
Four agents explore origin stories: compression, pedagogy, tooling, canon.
Open one, and you see the simulated prompt, critique, revision.
Kill a branch, and the reason stays in the file.
That is the point.
Pruned thought is evidence.
The losing branch still teaches.
Make it look visually stunning.
```

The seed script framed the problem:

```text
We have GitHub for code.
We do not have anything for thought.
Commits tell us what changed, not how the idea arrived.
Raw chat logs are chaos, like every take in a studio session.
AI work happens in loops: prompt, response, critique, branch, kill, revise.
```

The first concrete demo source was Andrej Karpathy's LLMWiki gist. The later quick-build version used Peter Steinberger's OpenClaw because the hackathon needed a static browser demo fast.
