# Follow Ups

Follow-ups are first-class primitives in AI work. This is where the project actually changed.

## Earlier Chat Context

```text
Write a prompt to help me build a demo that can show the most wow parts of my script.
This must be done in less than 30 minutes.
Actually loopthing the repo below.
Use Karpathy's LLMWiki gist.
Four agents explore origin stories: compression, pedagogy, tooling, canon.
Open one and you see simulated prompt, critique, revision.
Kill a branch, and the reason stays in the file.
Pruned thought is evidence. The losing branch still teaches.
```

## Demo Script Direction

```text
GitHub tracks code.
We do not have anything for thought.
Commits tell us what changed, not how the idea arrived.
AI work happens in loops: prompt, response, critique, branch, kill, revise.
A .loopthing stores nodes, edges, prompts, branches, critiques, kills, and reasons.
```

## Ralph Loop Direction

```text
Ralph Loop = the technique.
loopThing = the artifact.
The technique is: generate -> harsh critique -> regenerate -> force divergence -> kill weak branches -> loop again.
The artifact is a .loopthing file containing the tree, alive branches, killed branches, critiques, constraint vectors, and lineage.
```

## Filetype Correction

```text
Make the actual file .loopthing instead of .json.
A .loopthing is a file format for AI work: a forkable, auditable record of looping thoughts, branches, killed ideas, and revisions.
```

## Killed Repo Direction

```text
You cannot do a loopthing on a repo.
A repo is code output, not the prompt process.
LoopThing should turn a session and chat mess into artifacts.
```

## Container Correction

```text
A .loopthing is not a folder.
It is a collection of multiple file and artifact types inside a single portable container.
The viewer should feel like an OS for browsing the file.
```

## Rich Artifact Correction

```text
The loopthing itself generates net new artifacts and explainers.
It should help a new person understand, visualize, and appreciate the project.
It should feel like a modern rich PDF for AI work, with code, graphs, slides, screenshots, and useful context inside it.
```
