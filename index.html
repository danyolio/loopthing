The job is handoff.

The manual behavior already exists: people copy-paste old AI chats into new chats because they know the useful context is somewhere in there. LoopThing makes the stronger path obvious: scan local Codex and Claude Code history, pick the right conversations, then hand off the reasoning.

problem

"I don't know where my gold is."

Local AI history has the turns, but not the handoff. LoopThing pulls out the load-bearing moves without pretending raw logs are the product.

test

Five-minute recipient test

Can someone who was not in the conversation read the artifact and land where the creator landed?

artifact

Portable, forkable, auditable

The sealed file records source shape and role quality, then moves across chats, agents, collaborators, and future project sessions.

It keeps the dead ends useful.

Discarded branches are not trash. They stop the next person, or the next agent, from walking back into old traps.

  • Raw archive as product
    Rejected because storing everything preserves the mess instead of compressing it.
  • Viewer-first polish
    Rejected because a beautiful page can hide weak compression. The artifact has to be useful before the viewer earns trust.
  • Test fixtures as current source
    Rejected because fixtures are validation material, not the living project context.
  • GitHub repo framing
    Rejected because the current task is readability and product direction, not repository presentation.
